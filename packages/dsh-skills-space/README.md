# Skills Space for DeepSeek Harness

The DeepSeek Harness companion plugin for [Skills Space](https://github.com/arch3rPro/Skills-Space). Browse and manage skills in the DSH interface.

## Install

In DSH Desktop, open **Plugins → Add plugin**, enter `dsh-skills-space`, install it, and enable the plugin. The package supports DSH `>=0.2.2-rc.1 <0.2.3-0`.

The plugin is built from the [Skills Space source repository](https://github.com/arch3rPro/Skills-Space/tree/main/packages/dsh-skills-space). Issues belong in the [project issue tracker](https://github.com/arch3rPro/Skills-Space/issues).
