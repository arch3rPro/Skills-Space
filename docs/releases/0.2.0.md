# Skills Space 0.2.0

<!-- previous-release: v0.1.0 -->

本版以创意工坊和 DSH 配套插件为重点，同时整理跨 Agent 技能管理体验。

## 新增功能

- 创意工坊：选择可用智能体，通过对话创建和修改技能；工作台展示方案、执行过程及技能文件。
- 技能评估与优化：在详情页查看只读评估、历史结果和优化轮次；在工作台对话改进技能，并在确认后应用候选版本。
- 内置技能：随应用固定创作、评估和优化所用技能的版本，可在技能空间查看并检查更新。
- DSH 配套插件：在 DeepSeek Harness 中查看全局和当前项目技能、使用技能商店，并管理技能安装、更新、卸载及调用设置。

## 功能优化

- 技能管理页统一展示已托管和已发现的技能，整理筛选、分页、批量操作及多安装目录的详情展示。
- 更新随包的原版 `skills` CLI 至 1.8.1，并适配其技能发现和安装结果。
- 改进 DSH 插件在不同窗口宽度下的卡片、弹窗和筛选布局；全局及项目 Tab 显示各自的技能总数。

## Bug 修复

- 修正 DSH 插件中重复的本地目录来源选项，以及筛选范围与实际技能归属不符的问题。
- 修正创意工坊的会话续接、评估结果读取和优化候选应用过程中的状态问题。
- 修正创意工坊在 Windows 和 Linux 上的智能体启动路径与文件路径处理。
