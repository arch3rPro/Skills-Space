# Skills Space 0.1.0

<!-- previous-release: none -->

独立仓库首次发布，汇总当前版本的主要功能。

## 新增功能

- 跨 Agent 技能管理，统一查看全局与项目中的托管技能、原生技能及安装状态。
- 技能商店，提供 skills.sh 榜单、搜索、完整技能正文及安装说明。
- 支持 Git 仓库、本地目录与下载链接安装，支持跨 Agent、跨项目共享技能。
- Codex、Pi、Hermes 与 DeepSeek Harness 增强适配，提供各 Agent 的技能控制、配置及扩展管理能力。
- 技能更新、共享卸载检查、批量操作及项目锁文件恢复。

## 功能优化

首次发布，无上一正式版本；上述功能作为后续版本的比较基线。

## Bug 修复

首次发布，不将独立仓库发布前的内部修复列为版本间修复。

## 下载

| 系统 | 安装包 |
| --- | --- |
| macOS Apple Silicon | `Skills-Space_0.1.0_macos-arm64.dmg` |
| macOS Intel | `Skills-Space_0.1.0_macos-x64.dmg` |
| Windows x64 | `Skills-Space_0.1.0_windows-x64.exe` |
| Linux x64 | `Skills-Space_0.1.0_linux-x64.AppImage`、`.deb` |

macOS 包使用 ad-hoc 签名，尚未经过 Apple 公证；Windows 安装包尚未代码签名，首次打开可能出现系统安全提示。请核对仓库来源及随附的 `SHA256SUMS.txt`。

应用自动检测 Node，并在需要时准备兼容版本。Git 来源操作需要安装 Git。DSH 启停与调用控制需要在应用中安装配套插件。
