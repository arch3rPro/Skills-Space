# Domain documentation

Status: Active guidance. Reviewed 2026-10-13.

[The document index](../README.md) owns document status and navigation. [CONTEXT.md](../../CONTEXT.md) is the current shared glossary. It defines terms and their semantic boundaries; project constraints belong in [AGENTS.md](../../AGENTS.md), and requirements belong in active specs.

- Read the glossary and applicable active spec before changing domain behavior or terminology.
- Clarify overloaded terms, especially Agent detection, directory content, installation identity and actual loading. Do not infer one observation from another.
- Update the glossary when accepted meanings change; avoid a second glossary in a spec or implementation guide.
- Consult active ADRs for execution ownership, persistence and lockfile decisions. Check each ADR's status before treating its body as a current decision.
- Create an ADR for an accepted decision with meaningful, durable tradeoffs. Requirements, research, implementation plans and historical records have separate roles.
- Historical terms and instructions are evidence of earlier work, not current requirements. Domain documentation does not automatically invoke a skill.
