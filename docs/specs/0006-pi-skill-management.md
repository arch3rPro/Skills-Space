## 原生配置合同

以 [Pi 调研](../research/pi-agent-management.md) 和 [技能范围复核](../research/skill-management-scope-review.md) 固定的 Pi 1.1.0 源码为适配依据；不是对所有历史／未来版本的兼容保证。

- 全局配置位于 `PI_CODING_AGENT_DIR/settings.json`，未指定时为 `~/.pi/agent/settings.json`；项目配置位于 `<project>/.pi/settings.json`。
- 顶层 `skills` 保存额外路径及原生规则。`!pattern` 排除匹配项，`+path` 精确包含，`-path` 精确排除；精确排除优先于精确包含，后者优先于通配排除。
- 普通目录技能开关写入相应范围的原生精确规则；已有排除匹配项重新启用时移除对应精确排除并添加精确包含，不删除宽泛规则对其他技能的影响。
- 已安装本地包的技能过滤使用原生 `packages[index].skills`，保持包的其他资源设置。缺省过滤与空数组的含义不同；从空数组启用一个技能不能启用整包。项目包增量规则只读观察，暂不开放其卡片开关。
- 观察默认目录、附加目录、共享 `.agents/skills`、已安装包的技能清单及选择规则，处理真实路径去重、忽略文件和同名优先级。同名遮蔽、另一配置范围及增量规则均不冒充可直接切换。
- 只读检查不执行 Pi、扩展或包代码，也不为缺失包下载安装资源。旧版全局 npm 回退、无法定位的包／来源以及扫描上限通过提示表示限制，不能据此宣称已加载或已接管更新。
- 项目库存不混入全局库存；项目配置不被解释为对全局技能的通用覆盖。

## 写入和生命周期边界

Rust 负责配置校验、路径锁、并发版本核对、保留未知 JSON 字段、同目录临时文件和原子替换。配置格式错误、符号链接配置、锁占用或外部修改时拒绝覆盖；不会输出无关配置值。写入完成后重新观察配置状态。

这是明确授权的 Pi 原生技能配置扩展。托管技能的安装、更新、卸载仍调用固定未修改的上游 CLI；不改写其锁文件、不创建竞争性的安装数据库、不接管 Pi 包生命周期。额外／原生目录不因被发现而获得 CLI 卸载能力。`.agents/skills` 的原版共享安装语义保留。

新增 `minimatch@10.2.6` 和 `ignore@7.0.8` 是为对齐 Pi 的路径规则与忽略规则；随应用打包其依赖和许可证，不引入完整 Pi 运行时。

## Project installation ownership — 2026-10-17

Pi automatic discovery may load `.agents/skills` from ancestors, including HOME in a directory without a Git boundary. Runtime configuration scope and installation ownership are separate: the inspection snapshot retains inherited candidates for loading, exclusion and same-name precedence, while `inScope` controls inclusion in the current inventory. Only the selected project's own automatic roots, explicit project resources/packages, or corresponding global resources in global scope belong to that inventory. Ancestor-only resources are not current-project CLI targets or Trash candidates. A physical project entry linking to global content remains a project installation. CLI addressability is checked against the current target's canonical shared root, not both project and global roots.

Match Pi's user-root exclusion from ancestor discovery: HOME `.agents/skills` is loaded once with user settings, preserving global exclusions and user precedence. This does not alter the original skills CLI or infer a project's source from global lock records. Source and lifecycle remain scoped to actual installations.

## 2026-10-18 Invocation defaults and update safety (authorized)

This increment supersedes the unified-external native invocation contract above. CLI-managed physical resources stay external, including native aliases to their shared files. Independent Pi directory, configured Markdown and package resources use `disable-model-invocation` in their actual document. Explicit automatic selection writes `false`; manual-only writes `true`. Restore source default uses the recorded source token or removes the field when absent, retaining body, unrelated YAML, comments and line endings. An explicit, revision-checked field change may follow a manual field edit; automatic recovery never overwrites it or unrelated local content. One physical document has one invocation value across all referencing scopes.
