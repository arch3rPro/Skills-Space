在 [0007](0007-deepseek-harness-skill-management.md) 的 DSH 应用身份、通用目录及智能体分类基础上补齐原生管理。通用技能的安装、来源更新和共享卸载继续执行固定且未修改的原版 skills CLI（初批为 1.7.2，当前为 1.7.4）；本批不提供 `.dsh/skills` 安装器、不修改 CLI 或来源锁格式。分类保持“增强适配 / 通用支持”。

新增原生写入由 Rust 执行；Node helper 只读取数据、准备 YAML。只对已经核查的本机 `@deepseek-ai/dsh@0.2.0-rc.2` 开放写入，其他版本或版本未知继续只读。发行版本确认只读取命令路径及 package.json，不启动 DSH、插件、模型会话或有写入副作用的 dump-config。

## A 配置上下文与候选

设置按 Profile / preset / provider 选择检查上下文，并据此展示声明、目录与候选。该选择不切换 DSH 会话。未选择时仅扫描默认目录候选，不将不同 Profile 的附加目录合并为一份生效配置。选定声明停用默认目录时，不继续列入默认根；同名覆盖只在同一检查上下文内判定，调用均禁止的文件仍参与优先级。

仅传回技能相关白名单字段；动态表达式永不求值。不从未组合的 bundle、归档或运行时插件虚构库存，也不声称文件已进入当前会话。原版 CLI 安装前检查所选上下文；动态、覆盖根不匹配、默认目录关闭或无法确认的上下文拒绝 DSH 安装。未知上下文继续保守；无关 Profile 不自动否决已选且可确认的声明。

## B 三字段配置子集

仅编辑现有静态且身份唯一的用户 Profile 声明：`customSkillDirs`、`includeDefaultRoots`、`watch`。要求用户清单显式声明空 `dsh.profile.bundles`，无 extends/base、非空 HOME 覆盖、动态节点、YAML 锚点／引用／合并、身份重复或链接关系；否则只读，并提供打开原配置文件。附加目录要求绝对路径，UI 的 `~` 执行前展开。

不创建 Profile，不复制继承 preset，不写 HOME 补丁、缓存或安装包；其他根、提供器名称及高级监听参数只读。锁采用原生编辑器 `<profile>/package.json.lock` 的独占 PID 文件，不抢占已有锁。保存前复核配置依赖指纹、路径和原文，原子写入并回读三个字段；冲突要求重新读取，不覆盖、不自动重试。无关 YAML 字段与注释保留。页面切换、切换范围／检查上下文、刷新和关闭窗口保护未保存草稿。

## C 调用策略

只处理本范围 `DSH_HOME/skills` 或项目 `.dsh/skills` 中可证明独立的本地文件；共享 `.agents/skills`、CLI 托管、其他 Agent 共用、附加目录、插件／内置、`.system`、链接与硬链接均不提供原生写入。

| 选择 | disable-model-invocation | user-invocable |
| --- | --- | --- |
| 模型与手动调用 | false | true |
| 仅手动调用 | true | true |
| 仅模型调用 | false | false |
| 禁止调用 | true | false |

修改官方元数据键，不增加应用侧禁用表。禁止调用不表示从发现结果排除，也不释放同名优先级。操作修改物理文件，影响所有读取者；保留正文、其他元数据、注释和换行。逐文件指纹校验，原子写入并回读。详情通过既有“更多技能操作”修改调用方式，原生集合多选沿用 Pi 批量菜单；卡片不放调用控件；按文件身份处理批量，失败停止并报告已完成数量，不重试、不回滚先前成功项。

## D 废纸篓卸载

与 C 采用同一独立性边界，另外完整检查目录内容指纹、嵌套技能／配置目录、文件数量与大小。确认展示实际目标：目录技能连同目录内附件移至 OS 废纸篓；扁平 Markdown 只移动该文件，同目录附件和其他技能保留。不移动父根，不改配置及 CLI 来源锁；确认后再次验证。复用 Pi 的有界内容审查和 OS 废纸篓通道，DSH 单独判断资格。失败不回退永久删除。
