# 创意工坊交互原型

日期：2026-11-04。分支：`codex/skill-workshop`。状态：独立前端原型，不代表创意工坊后端已交付。产品方案见 [0013](../specs/0013-skill-workshop.md)。

## 打开

在项目根目录运行：

```sh
pnpm exec vite --host 127.0.0.1 --port 1422 --strictPort
```

浏览器打开 [创意工坊原型](http://127.0.0.1:1422/workshop-preview.html)。独立入口不替换正式应用主页。源代码为 `workshop-preview.html`、`src/workshop-preview-main.tsx` 和 `src/workshop-preview.tsx`。

## 当前可体验内容

- 卡片默认进入原有技能详情，复用预览／源码；卡片或详情的“工作台”动作打开工作台；进入本身不开始调用智能体。新建后直接开始创作对话。
- 连续消息完成提出要求、反馈方案、确认构建和后续修改，不再通过多个表单串接。
- 工作台为对话／文件正文／最右目录树三段式；正文与目录作为统一文件区，顶部文件图标入口负责展开，目录顶部关闭按钮负责整体关闭，关闭后对话占满工作台。文件选择、输入和会话按创作保留，点击引用可重新展开；工作台无预览／源码标签。
- 方案变更自动更新方案文件，确认后才生成技能目录；运行活动和停止留在对话中。
- 原安装、试用、评估仍是可选操作，不加入创作核心步骤。原型数据均为模拟。

文件树复用 Button 的 navigation 行变体与 Collapsible，合并连续单子目录；不再使用应用侧栏组件。输入复用 Card、Textarea、Button，正文复用 SkillMarkdown。内外两层横向分栏使用官方 shadcn Resizable 与 react-resizable-panels@4.17.0；查看复用 SkillDetail／SkillDetailMetadata／SkillDocument，通过可选附加视图加入评估 Tab。
