# 技能工作台想法与入口收敛

日期：2026-10-15。状态：下文保留早期想法和入口收敛的历史记录。2026-11-04 已完成 Codex／Pi 最小验证，当前建议方案见 [0013 创意工坊](../specs/0013-skill-workshop.md)，用户已确认设计，正式首批接入中；旧隐藏入口保持原状，新模块独立实现。

## 工作台方向（待重新调研）

围绕同一个技能目录衔接创建、编辑、试运行和安装，不做强制逐步向导：

```text
技能工作台
├─ 技能列表：新建／打开已有目录
└─ 当前技能
   ├─ 顶部：名称、目录、保存状态；保存／试运行／安装
   ├─ 编辑：文件树和编辑区，初期优先 SKILL.md
   └─ 试运行：Agent、任务、状态和日志；可返回编辑
```

- 创建生成初始技能文件并进入编辑；编辑与试运行可反复切换。
- 试运行使用已保存的内容，不隐式安装到正式技能目录，也不等同于自动质量验收。
- 安装优先复用现有来源预览、范围、Agent、链接／复制及结果查看流程；不强制先试运行。
- 文件树／其他文件编辑、目录所有权、直接编辑已安装或共享技能的影响、保存和试运行边界、调用方式及上游接口都需要重新调研，不能直接将上述草图实现为完整 IDE。
- 不恢复中心技能库、分发记录或通过移动链接实现技能启停；不扩展为通用 Agent 管理。

## 本次实施的入口调整

- Agent 页面顶部路径左侧增加文件夹图标，图标和路径作为同一个可点击、可键盘激活的区域，打开当前显示的目录；标准目标目录不存在时禁用。
- 隐藏技能测试和创建技能的现有入口，包括技能库存菜单、详情菜单和技能商店来源页的测试按钮。保留现有底层能力、流程和上游实现；工作台落地前不提供占位入口，不暗示已实现创作能力。
- `src/App.tsx` 的 `showSkillAuthoringActions` 控制这些入口，当前为 false。后续不能只打开开关就视为完成工作台，需先完成重新调研及设计确认。
- 添加技能从页面标题区移到托管技能工具栏右侧，原生技能页不显示；保留当前范围和 Agent 预选行为。窄窗口沿用现有工具栏图标收敛规则及可访问名称。
- 打开 Agent 目录移出库存更多菜单；项目托管页的依赖安装、锁文件恢复仍保留。没有任何菜单项时隐藏更多按钮。
- 详情页的打开技能目录、受支持的按来源卸载继续保留；此次调整不移除技能详情中的实际操作能力。
