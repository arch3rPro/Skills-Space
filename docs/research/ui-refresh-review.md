## 整页核查与对应调整

| 问题 | 对应调整 |
| --- | --- |
| 页面导航、筛选和选项都像一排描边按钮，视觉职责混淆 | 商店／设置使用下划线 Tabs；排行榜及明暗选项使用紧凑分段控件 |
| 工具栏堆叠创建、依赖、恢复、临时使用等操作 | 标题区保留添加技能与范围；工具栏保留搜索、筛选、更新、刷新；低频操作按组放入更多菜单 |
| 详情页四个操作争夺标题空间 | 安装到其他 Agent 为主要操作；目录、临时使用与来源卸载归入菜单；标题与描述可换行 |
| 技能卡片留白、阴影及边框过重，来源只有图标 | 缩减卡片空白，描述两行摘要、名称单行缩略；显示来源文本（无记录时明确标识），完整名称／描述可悬停或进入详情查看 |
| Agent 路径与计数挤在标题同一行 | 路径单独一行缩略并提供完整提示；保持 `~` 展示 |
| 安装和依赖弹窗需要翻找全部 Agent，卡片嵌套边框 | 共用搜索选择器，已检测 Agent 排前，显示选中数量与名单；减少框线，保留品牌图标与检测语义 |
| 向导步骤没有明确进度 | 共用编号与完成标记的步骤指示器，当前步骤有语义标记 |
| 按钮被纵向布局拉满、长正文挤走操作 | 共用明确的 ModalActions 底部插槽；正文独立滚动，操作区换行；关闭后恢复触发按钮焦点 |
| 来源输入与文件夹按钮分散 | 共用 SourceField，输入与目录选择同一行；可点击字段标签 |
| 创建字段的外层 label 包住输入和按钮，导致按钮名称错误 | 创建目录使用 Field／FieldLabel，输入与目录按钮分别命名 |
| 加载只剩一段文字，空状态无入口，部分流程直接抛出原始错误 | 卡片骨架；库存空状态可添加或清除筛选；安装、创建、依赖、恢复、临时使用共用 FlowError，先显示下一步，诊断展开查看 |
| 配色与明暗模式混用，字体不可配置 | 八套准确来源主题，默认 vercel；明暗独立，四类字体、14／16／18px；旧偏好缺失字段兼容 |
| Agent 图标全集与临时使用流程加入首包 | 保留原品牌资源，按需导入；建立 Agent／计数映射；库存筛选延后渲染，保留排行榜既有防抖 |
