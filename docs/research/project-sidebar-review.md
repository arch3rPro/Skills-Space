# 全局与项目 Agent 侧栏

日期：2026-10-14。状态：已实施，桌面与偏好验证完成；下列验证边界保留。

## 实现

- 保留独立“技能空间”导航，用于当前范围的技能汇总；移除列表页范围选择。全局与多个项目分别提供 Agent 入口，点击时设置实际 global/project 目标并清空上个范围库存；页面显示范围名称、Agent 名称和技能目录。
- 全局管理、项目管理的折叠箭头位于文字之后；项目标题保留内置图标，无表情符号、拖动手柄和折叠箭头。项目标题直接拖动，单击折叠；Enter/Space 提供键盘折叠，上下方向键提供排序。所有 Agent 行复用相同侧栏行，统一右移 12px，不逐层叠加缩进。
- 新增按钮和项目更多按钮置于各自标题行内；更多按钮使用无独立外框的紧凑样式，二级菜单从按钮下方向下弹出、间距 8px，宽度自适应内容，复用菜单阴影和条目布局；操作文案为“移除项目”，仍只移除记录。
- 项目编辑支持目录选择、名称（默认目录名）、16 个内置图标及中英文搜索。校验必填与重复目录；名称、图标仅影响显示，移除记录仅影响偏好，不删除目录或技能。目录不存在时保留记录，读取失败可以重试或通过编辑重新选择目录。
- 项目数组保存顺序，collapsedSections 保存折叠状态。原字符串项目路径自动迁移为目录名与文件夹图标。安装向导以项目名称展示范围，仍传入真实目录，并保留当前 Agent 预选。
- 范围侧栏按展开状态读取库存并缓存。生命周期代码和固定原版 CLI 未改；没有跨范围汇总、远程执行或新运行时依赖。

## 分类、hover 与单击交互调整

- 分类标题取消背景，字号由紧凑按钮字号改为 text-sm，使用 muted-foreground。折叠箭头与新增按钮默认透明，hover/focus-within 时显示，保留键盘可操作性和固定占位。
- 项目标题与更多按钮共享整行 hover/focus 背景，更多按钮取消独立 hover/open 背景。单击切换项目折叠；拖动结束抑制紧随的 click，避免排序时同时折叠。键盘 Enter/Space 仍可切换折叠。
- 所有范围的 Agent 行统一增加 12px 左侧缩进，项目本身不叠加缩进。项目菜单改为向下、末端对齐，移除最小宽度限制并按内容展开；“移除项目”仍调用原有移除记录处理。
- 最终 pnpm build、18 项前端契约、CI=false pnpm tauri build --debug --bundles app 与 git diff --check 通过。隔离桌面验证单击折叠、无手柄标题拖动排序后保持展开、菜单条目及“移除项目”文案。最终截图确认默认分类无背景且箭头/新增隐藏、Agent 缩进，以及菜单位于更多按钮下方、宽度自适应；本轮实际捕获弹出菜单，更新前轮视觉验证缺口。
- 原生偏好和 CLI 未改，不重跑原生生命周期测试；不修改真实项目或技能。
